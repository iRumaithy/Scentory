# Scentory 2 — خزانة العطر

إعادة بناء كاملة لمكتبة العطور الشخصية: معرض بزجاجات كاملة، رسومات للنوتات، بحث عربي/إنجليزي، مقارنة حتى ثلاثة عطور، خزانة ومذكرة تجارب وبصمة مستخرجة من اختيارات المستخدم.

## البيانات والصور

- 573 عطرًا من 21 دارًا في النسخة المؤرخة 20 أكتوبر 2026.
- 543 صورة رسمية، و432 ملف نوتات موثقًا من المصدر. البقية معلّمة بوضوح كبيانات سابقة أو غير متاحة.
- لا تُعرض تقييمات مجتمعية أو نسب تركيبة أو أرقام ثبات مخترعة. الثبات والفوحان في المذكّرة من تجربة المستخدم نفسه.
- الصور الأصلية تُعرض باستخدام `object-fit: contain` بلا أقنعة أو اقتصاص. رسومات النوتات SVG أصلية حسب المادة والعائلة.
- توثيق المصدر وتاريخ المراجعة محفوظان مع كل سجل. الكتالوج لا يدّعي احتواء جميع العطور عالميًا.
- مصادر الصور الخارجية تتطلب اتصالًا؛ الواجهة والكتالوج والمكتبة المحفوظة تعمل دون اتصال بعد أول فتح ناجح.

## التشغيل والتحقق

```sh
npm ci
npm test
npm run dev
```

تُختبر عمليات البحث والتصفية، استعادة قوائم الإصدار السابق، المقارنة، ملاحظات المستخدم، عزل الحسابات، تعارض تعديلات الأجهزة، بيانات الكتالوج وأيقونات PNG. الاختبارات التي تستخدم DOM لا تثبت العرض الفعلي على Safari؛ راجع نسخة التجربة على الآيفون قبل اعتماد النشر العام.

## النشر على Cloudflare الحالي

مصدر Worker هو `src/index-v200.js`، مع Static Assets في `public/` وربط D1 باسم `DB`.

**قبل نشر الواجهة الجديدة، طبّق migrations على قاعدة البيانات المرتبطة بالتطبيق:**

```sh
npm run db:migrate:remote
npm run deploy
```

لا تستبدل قاعدة البيانات الحالية ولا تحذف حساباتها. migration `0003_personal_archive.sql` يضيف أرشيفًا لكل مستخدم. أول قراءة تستعيد قوائم الحساب وملاحظاته من جداول الإصدار السابق. تحفظ ملفات JSON الجديدة المستخدم الحالي فقط، مع مراجعات متزايدة تمنع جهازًا قديمًا من الكتابة فوق جهاز آخر.

بيانات الجهاز القديم في `scentory-b-v1` تظل قابلة للاستعادة؛ النسخة الجديدة تستخدم مفاتيح منفصلة للحسابات. استيراد النسخ الاحتياطية يدمج ولا يحذف البيانات الحالية.

## النسخة الخاصة في Sites

نسخة تجربة مستقلة، محمية بخصوصية المالك في Sites، ولها D1 منفصل عن قاعدة التطبيق الحالي. لا تنقل بيانات الإنتاج تلقائيًا. يمكن تجربة المكتبة محليًا، وتتم مزامنتها تلقائيًا لهوية المالك في Sites، أو استيراد نسخة JSON. لا تتطلب نسخة Sites كلمة مرور إضافية.

البناء `npm run build` يتطلب `.openai/hosting.json` لهوية المشروع الخاص وربط `d1: "DB"`. ينتج Worker ESM مستقلًا وأصوله وmigration محددًا داخل `dist/`. لا تحفظ هوية Sites أو بيانات الاعتماد في مستودع التطبيق العام.

## تحديث الكتالوج

```sh
npm run catalog:refresh
```

المجمّع في `scripts/refresh-catalog.py` يقرأ كتالوجات دور العطور العامة فقط. لا ينسخ وصفها التسويقي إلى التطبيق ولا يجمع مراجعات مجتمعية. يُراجع التحديث ويُختبر قبل دمجه؛ لا يُنشر مباشرة إلى المستخدمين. راجع `docs/CATALOG_V2.md` لتفاصيل التغطية والقيود.

مسار البحث التجريبي القديم PerfumAPI متوقف في الإصدار الجديد. لم تُغيَّر ملفات migrations القديمة.
