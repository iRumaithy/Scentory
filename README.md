# Scentory — Cloud Sync Edition

واجهة Scentory الفاخرة مع Cloudflare Worker + D1.

## ما تم إضافته

- إنشاء حساب وتسجيل دخول باسم مستخدم وكلمة مرور.
- جلسة دائمة في Cookie آمنة حتى تسجيل الخروج (مع تجديد مدة الجلسة عند فتح الموقع).
- مزامنة المفضلة / أملكها / أريد تجربتها / أريد شراءها بين الأجهزة.
- تقييم شخصي من 10 وملاحظة لكل عطر مع مزامنة D1.
- استمرار الحفظ المحلي للزائر قبل تسجيل الدخول.
- دمج القوائم المحلية مع السحابية عند أول تسجيل دخول لتقليل خطر فقدان البيانات.
- Cloudflare D1 يتم Provision تلقائيًا عند أول deploy عبر Wrangler الحديث.
- Worker ينشئ الجداول تلقائيًا عند أول API request؛ ملف migration مرفق أيضًا للإدارة المستقبلية.

## Cloudflare

الإعداد في `wrangler.jsonc` يربط Static Assets وWorker API وD1. المسارات `/api/*` فقط تمر أولًا عبر Worker، بينما ملفات الواجهة تبقى Static Assets.

بعد رفع هذه الملفات إلى فرع `main`، Cloudflare Git deployment سيقوم بـ deploy. إذا كان Worker مربوطًا بالمستودع نفسه، سيظهر D1 binding باسم `DB` تلقائيًا في Dashboard بعد النشر.

## فحص سريع بعد النشر

افتح:

`/api/health`

يجب أن ترى JSON يحتوي `ok: true` و `database: "ready"`.

بعدها افتح الموقع واضغط بطاقة الحساب لإنشاء أول مستخدم.
