# Scentory 50-perfume catalog

This expansion adds 38 curated records to the original 12, for 50 total.

- Existing 12 records retain their approved local product images.
- New records intentionally use a clean transparent placeholder until a licensed, high-resolution product cutout is approved. This prevents low-quality or legally uncertain imagery from entering the production catalog.
- `accords` values are visual rank weights, not measured percentages. The interface suppresses the percent label.
- New records do not display fabricated community ratings.
- Note imagery is mapped only when the ingredient mapping is explicit; abstract accords use neutral material visuals.
